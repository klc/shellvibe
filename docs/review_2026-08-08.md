## 🔴 Blocker / Yüksek Riskli Dosya Bulguları

### 1. `identity_form_dialog.dart` — SSH Key İle Bağlantıda Kullanıcı Adı Siliniyor ve Gizleniyor (Kritik SSH Hasılatı)
- **Nerede:** [`lib/features/vault/presentation/dialogs/identity_form_dialog.dart:188, 201-260`](file:///Users/mkilic/www/klc/terly2/lib/features/vault/presentation/dialogs/identity_form_dialog.dart#L188)
- **Ne oluyor:** Kullanıcı vault'a kimlik eklerken Kimlik Tipi olarak `SSH Private Key` (`key`) seçtiğinde, kod `_usernameController.clear()` çağırarak kullanıcı adını silmekte ve form üzerinde Username alanını gizlemektedir. SSH Private Key ile yapılan bağlantılarda kullanıcı adı (örn: `ubuntu`, `root`) zorunludur. Kimlik veritabanına `username = ""` olarak kaydolmakta ve bu kimliği kullanan tüm SSH bağlantıları kimlik doğrulama aşamasında reddedilmektedir.
- **Etkisi:** Kullanıcılar vault üzerinden kaydettikleri hiçbir SSH anahtarı ile sunuculara bağlanamaz.
- **Fix:** Username alanını `key` kimlik tipinde de formda görünür kılın ve `clear()` çağrısını kaldırın.
- **Efor:** S

### 2. `terminal_tabs_notifier.dart` — Kapatılan Tab'ın Diriltilmesi (Async Race Condition)
- **Nerede:** [`lib/features/terminal/presentation/notifiers/terminal_tabs_notifier.dart:199-224`](file:///Users/mkilic/www/klc/terly2/lib/features/terminal/presentation/notifiers/terminal_tabs_notifier.dart#L199-L224)
- **Ne oluyor:** `_connectSshTab` metodu el sıkışması yaparken (`await sessionManager.connect(...)`), kullanıcı bağlanan tab'ı kapatırsa tab listeden kaldırılır. Ancak `await` tamamlandığında kod tab'ın hâlâ açık olup olmadığını kontrol etmeden `tab.isConnected = true` yapıp disposed tab'ı tekrar `state.tabs` içine eklemektedir.
- **Etkisi:** Kullanıcının kapattığı sekme arka planda el sıkışması bitince aniden ekrana bozuk/yetim sekme olarak geri gelir.
- **Fix:** `await` sonrasında `if (!_ownedTabs.contains(tab)) { await sessionManager.close(); return; }` kontrolünü ekleyin.
- **Efor:** S

### 3. `terminal_tabs_notifier.dart` — Bağlantı Hatalarında Socket Sızıntısı (Resource Leak)
- **Nerede:** [`lib/features/terminal/presentation/notifiers/terminal_tabs_notifier.dart:187-244`](file:///Users/mkilic/www/klc/terly2/lib/features/terminal/presentation/notifiers/terminal_tabs_notifier.dart#L187-L244)
- **Ne oluyor:** SSH bağlantısı başarısız olduğunda `catch` bloğu `jumpSessionManagers` nesnelerini kapatmakta ancak `tab.sshSessionManager` nesnesini `close()` etmemekte ve `null` yapmamaktadır.
- **Etkisi:** Başarısız bağlantı denemelerinde açılan TCP socket'leri ve zamanlayıcılar bellekte askıda kalır.
- **Fix:** Hata bloğuna `await tab.sshSessionManager?.close(); tab.sshSessionManager = null;` ekleyin.
- **Efor:** S

### 4. `sftp_transfer_queue_worker.dart` — İndirme/Yükleme Kuyruğunda Force-Unwrap Crash Risk
- **Nerede:** [`lib/features/sftp/data/sftp_transfer_queue_worker.dart:315, 374`](file:///Users/mkilic/www/klc/terly2/lib/features/sftp/data/sftp_transfer_queue_worker.dart#L315)
- **Ne oluyor:** `_performDownload` ve `_performUpload` metotlarında `final item = _queue[id]!;` satırında `!` force-unwrap kullanılmaktadır. Transfer devam ederken başka bir işlem (örneğin kuyruk temizleme) öğeyi silerse `Null check operator used on a null value` crash'i fırlatılır.
- **Etkisi:** SFTP kuyruk işlemleri sırasında uygulama beklenmedik şekilde çöker.
- **Fix:** `final item = _queue[id]; if (item == null) return;` şeklinde güvenli kontrol yapın.
- **Efor:** S

### 5. `sftp_transfer_queue_worker.dart` — Duraklatılan SFTP İndirmelerinde Dosyanın Silinmesi (Data Loss)
- **Nerede:** [`lib/features/sftp/data/sftp_transfer_queue_worker.dart:321-365`](file:///Users/mkilic/www/klc/terly2/lib/features/sftp/data/sftp_transfer_queue_worker.dart#L321-L365)
- **Ne oluyor:** Kullanıcı devam eden bir indirmeyi duraklattığında (`_pauseFlags[id] == true`), `completedSuccessfully` değeri `false` kalır. `finally` bloğu duraklatılan işlemi hata/iptal sayarak kısmen indirilmiş yerel dosyayı komple siler.
- **Etkisi:** Duraklatılan büyük indirmeler sıfırlanır, kullanıcının verisi ve kotası kaybolur.
- **Fix:** Duraklatma (`pause`) ile İptal (`cancel`) durumlarını ayırın; duraklatmada kısmi dosyayı silmeyin.
- **Efor:** M

### 6. `vault_key_service.dart` — Vault Kilitlenme Riski (Incomplete State Lockout)
- **Nerede:** [`lib/features/vault/data/vault_key_service.dart:46-48`](file:///Users/mkilic/www/klc/terly2/lib/features/vault/data/vault_key_service.dart#L46-L48)
- **Ne oluyor:** `isMasterPasswordConfigured()` yalnızca `masterSalt` anahtarının depolamada varlığını doğrular. Eğer master parola belirleme sırasında `wrappedDek` yazılamazsa veya işlem kesintiye uğrarsa `isMasterPasswordConfigured()` `true` döner ancak `unlock()` metodu `wrappedDek == null` yüzünden başarısız olur.
- **Etkisi:** Kullanıcı vault'a bir daha asla erişemez ve kilitli kalır.
- **Fix:** Hem `masterSalt` hem de `wrappedDek` varlığını zorunlu kılın: `hasSalt && hasWrapped`.
- **Efor:** S

### 7. `tunnel_engine.dart` — Kapatılmayan StreamController (Analyzer Warning)
- **Nerede:** [`lib/core/network/tunnel_engine.dart:121`](file:///Users/mkilic/www/klc/terly2/lib/core/network/tunnel_engine.dart#L121)
- **Ne oluyor:** `watchActiveTunnels()` içindeki `StreamController` nesnesi `close()` edilmemektedir (`close_sinks` uyarısı).
- **Etkisi:** Bellek sızıntısı ve statik analiz uyarısı.
- **Fix:** `onCancel` bloğunda `controller.close()` çağrısını ekleyin.
- **Efor:** S
